## 🧩 About

**2XKO ESP Menu** is a curated list of 2XKO open-source tools:

- **Overlays** — on-screen helpers, layout notes, hitbox viewer, frame data display
- **Quality-of-Life Helpers** — combo catalog, skin manager, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Frame Data Overlay — visualize startup, active, and recovery frames
- Hitbox Viewer — show attack and hurtbox outlines for study
- Replay Notes — record and review match runs
- Playback Speed — adjust training playback for study (0.1x to 5x)

### Wallhack
- Skin Catalog — browse character skins and colors
- Custom Palette Notes — organize player cosmetics
- Hit Spark Visibility — improved hit effect clarity

### Aimbot
- Training Mode Notes — segment study on any matchup
- Counter Hit Indicator — manually flag counter hits mid-match
- Input Buffer Notes — chain complex maneuvers in the lab

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"Tab"` | Toggle overlay |

## 🛠️ Troubleshooting

- **Overlay not showing**: Ensure the game is running in windowed or borderless mode and the process name matches `2XKO.exe`.
- **Hotkey conflict**: Change `menu_hotkey` in the config file to a key not used by the game.
- **Antivirus flag**: Some tools may be flagged due to overlay injection; add an exclusion for the extracted folder.
- **Game crash on launch**: Disable `safe_mode` if you have verified the game version is compatible, or run as administrator.
- **No frame data**: Make sure the overlay is updated to match the current game patch.
